# v0.2.0 完整状态回放的固定验收目标

[固定目标与输入哈希](state-resource-target.json)在新回放实现之前记录。使用 RIS rrc23 2025-01-01 完整 RIB 和连续十二个五分钟 UPDATE，完整解码 1,597,926 条记录、11,946,097 条路由事件和 749 条会话事件，不缩减 peer 或前缀。分析窗口为 00:00:00–00:59:59 UTC，显式基线不计窗口统计。

资源目标为每轮 **2 GiB 峰值 RSS、120 GiB 新增临时/结果文件、两小时**，至少三轮。硬件、起始可用内存、版本、来源及文件 SHA-256 在 JSON 中固定。此目标与历史 1400 MiB 的失败基准分开；增加预算并不代表已经成功。

允许使用磁盘保存完整逻辑状态，但不允许无提示过期或淘汰路由。每轮必须完成全部输入、基线、预热、窗口分析、变化输出与最终状态导出；分别记录解析、分区、状态驻留、序列化及写出成本，核对计数与结果指纹。新实现须与可完成的小规模完整内存参考比较来源、变化、状态、会话重置和乱序语义。

完整回放成功与否由实际测量判定；失败保留证据。内存剖析的部分输入仅用于组件测量，不作为完整回放成功证据。
