# v0.2.1 工具链整改复验

[验证导航](README.md) · [原 v0.2.0 验收](v0.2.0-acceptance.md) · [机器收据](toolchain-v0.2.1.json)

验证日期：2026-10-29。本次将实际编译器升级为 **moonc v0.10.18+6c83a7f62（2026-10-28）**，Moon 为 0.1.20261028，满足 moonc 不低于 0.10.16 的验收门槛。`moonbit-toolchain.version` 固定相同发布标签，主 CI 和 Copilot 准备工作流均读取该文件。

## 实现整改

- `scripts/check_toolchain.mjs` 运行真实 `moonc -v` 并检查最低版本；`npm run build`、`npm test` 和两个工作流都执行该检查。回归测试覆盖旧版拒绝、错误工具版本拒绝、最低版本与后续版本接受。
- 迁移 46 处已废弃的标准库 JSON 转换调用，保留 `--deny-warn`。新格式化器将整数别名写为 `Int32/UInt32`；两份公开接口与原接口在统一这些别名后完全一致，没有新增或删除接口，JSON/CSV 输出模式仍为 2.0。
- 将 README 三个示例命令加入 CI。源码包审计包含版本文件、版本检查脚本、CLI 资产与隐私材料排除，解包后重新编译。

## 历史数据与浏览器边界

18 个完整档案对照、三轮完整状态回放、紧凑编码、百万观测关联及大报告性能数据，继续绑定原版本和原工具链。本轮没有重跑这些长时测量，不将旧数字改写为 0.10.18 的性能结论；原 v0.2.0 标签、Release 和 Mooncakes 包保留。
