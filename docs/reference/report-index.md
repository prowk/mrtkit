# 离线报告索引与导航

报告将完整事件页与筛选倒排索引分离。每 8,192 行建立一个索引块，分别记录观测点、前缀、peer、提醒类型、来源身份和关联组的行号列表，行号以差分变长整数和 Base64 编码。筛选只读取索引块，组合条件取交集；结果是每行一位的位图，100 万行约 122 KiB，不保存全部匹配对象或属性。明细仅为当前 50 行加载所需数据页，分页顺序与原报告一致。

筛选显示索引进度；取消和重置增加请求版本，过期请求不能写入当前结果。取消保留上次完整结果。分块加载失败或超时明确显示错误。所有文字通过 `textContent` 写入，数据 JSON 中的 `<`、U+2028 和 U+2029 转义，不调用 `fetch` 或外部资源。

`report --correlation 关联包/index.json` 附加分离式关联结果。先核对关联包绑定的原回放索引 SHA-256、窗口、观测点、文件哈希及计数，再用外部排序检查所有分组引用和逐组计数。摘要、观测明细分别分页；组内观测通过来源身份索引跳转到完整事件。报告继续展示输入部分状态、基线、连续性和缺档；未观测到提醒仅表示该范围没有匹配证据，不解释为传播时延或因果。

变化解释展示规范化 AS 路径、由核心计算的起源 AS、ORIGIN、下一跳、社区、MED、LOCAL_PREF 和聚合属性的前后值，标注未知、空集合及未变化字段。规范化复用 MoonBit；原始 JSON 和前后来源仍保留。同一来源事件的不同提醒可通过按钮集中查看。

隔离 DOM 回归测试覆盖 17,000 行的三块索引、组合筛选、分页、取消后重置、恶意文字、关联计数和来源跳转。此类测试只验证逻辑，不能代替本地真实浏览器的布局和性能验收。
